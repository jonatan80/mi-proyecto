# 📊 Proyecto 1 — Análisis de Inventario

## 📌 Descripción

Este proyecto presenta un análisis exploratorio de datos (EDA) aplicado a un conjunto de datos de inventario de productos tecnológicos.

El objetivo es analizar el comportamiento del inventario, identificar los productos con mayor y menor participación y obtener información útil para apoyar la toma de decisiones.

## 🎯 Objetivos

- Explorar y comprender los datos del inventario.
- Realizar limpieza y preparación de los datos.
- Analizar productos y categorías.
- Identificar niveles y movimientos del inventario.
- Crear visualizaciones para facilitar la interpretación.
- Obtener conclusiones y hallazgos relevantes.

## 🛠️ Herramientas utilizadas

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 📈 Seaborn
- 📓 Jupyter Notebook

## 🔎 Proceso de análisis

1. Carga de los datos.
2. Exploración inicial.
3. Limpieza y transformación.
4. Análisis estadístico.
5. Agrupación y comparación de información.
6. Creación de visualizaciones.
7. Identificación de hallazgos.
8. Elaboración de conclusiones.

## 📊 Resultados

El análisis permite identificar patrones importantes relacionados con los productos, categorías y niveles de inventario, facilitando la interpretación de la información y la toma de decisiones.

## 💡 Principales aprendizajes

Este proyecto permitió aplicar conceptos fundamentales de análisis de datos utilizando Python y Pandas, desde la limpieza de información hasta la generación de visualizaciones y conclusiones.
