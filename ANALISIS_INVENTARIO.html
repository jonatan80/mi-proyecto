12. CONCLUSIONES Y HALLAZGOS¶

Objetivo del análisis¶

El objetivo de este proyecto fue realizar un análisis exploratorio de un inventario de productos tecnológicos, utilizando Python y Pandas para identificar la distribución de los productos y categorías presentes en la base de datos.

Principales resultados¶

  • El conjunto de datos contiene 1.000 registros.
  • La información está organizada en tres variables: ID, Producto y Categoría.
  • No se encontraron valores nulos en ninguna de las columnas.
  • Se identificaron 6 categorías de productos.
  • La categoría con mayor presencia es Periféricos, con 508 registros, equivalente al 50,8% del inventario.
  • La categoría con menor presencia es Redes, con 49 registros.
  • Los productos con mayor frecuencia son Teclado (171) y Mouse (170).
  • El análisis permitió identificar los productos y categorías con mayor participación dentro del inventario.

Hallazgos¶

Los resultados muestran una concentración importante del inventario en la categoría Periféricos. Esto indica que estos productos representan una parte significativa de la oferta analizada.

También se observa una alta frecuencia de productos como teclados y mouse, por lo que podrían requerir un seguimiento especial para mantener una disponibilidad adecuada.

Recomendaciones¶

  1. Realizar un seguimiento periódico de la categoría Periféricos.
  2. Mantener un control especial sobre los productos con mayor frecuencia.
  3. Revisar periódicamente las categorías con menor representación.
  4. Actualizar la base de datos de inventario de manera periódica.
  5. Utilizar el dashboard como herramienta de apoyo para el seguimiento del inventario.

Conclusión¶

El análisis exploratorio permitió transformar una base de datos de inventario en información útil para comprender la composición de los productos y categorías. El uso de Python, Pandas y visualizaciones facilitó la identificación de patrones y permitió construir un dashboard que resume los principales resultados del inventario.
